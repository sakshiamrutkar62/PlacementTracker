1. Project Overview — What Is This?

Placement Tracker is a smart, AI-powered web application that brings together students, college placement officers, and companies in one single, trusted platform. Think of it as a private job board — but much smarter.

Unlike open job boards like LinkedIn or Naukri where anyone can post anything, this is a closed, college-controlled ecosystem. Only students from the college can register, and only verified internship listings are shown.

The Core Problem It Solves: Students write skills on their resume that they don't actually know. Recruiters waste hours interviewing wrong candidates. This platform fixes that by making students prove their skills through AI quizzes before they can claim them as "Verified".

The Three Main Goals

🎓
For Students

Upload your resume, get your skills extracted automatically, find internships that match your skills, verify your abilities through AI, and track every application in real time.

🏫
For Placement Officers (Admin)

Post internship listings, manage all student applications from one dashboard, shortlist or reject candidates, verify students officially, and rank students by performance.

🤖
AI-Powered Intelligence

Google Gemini AI generates fresh quiz questions on the fly so students can't memorise answers. It also creates personalised 30-day learning plans for skill gaps.

🔒
Trusted & Secure

Encrypted passwords, secure login tokens, rate limiting to prevent abuse, and input sanitisation to block malicious attacks — all built in by default.

4. Complete Student Workflow — Step by Step

This section walks you through every single thing a student can do on this platform, from creating an account to getting a job offer.

4.1 Register & Login

Page: register.html to sign up → index.html to log in

Registering a New Account

  • 1
    Go to http://localhost:3000/register.html. Fill in your Full Name, Email, Password, Batch Year, and select role as student.
  • 2
    Click Register. The system checks whether the email is already taken. If not, your password is encrypted (hashed) and saved — nobody, including the admin, can ever read your original password.
  • 3
    You are immediately given a secure digital token (JWT) and taken to your student dashboard.

Logging In

  • 1
    Go to index.html. Enter your email and password.
  • 2
    The server verifies your credentials. A secure token (valid for 7 days) is sent back and saved in your browser.
  • 3
    Every time you take an action (apply, upload resume, etc.), this token is automatically sent with the request to prove it's you. If the token is missing or forged, the server blocks the request.

4.2 Forgot Password / Reset Password

Page: Link on login page → reset-password.html
  • 1
    Click "Forgot Password?" on the login page. Enter your registered email.
  • 2
    The system generates a random one-time reset token and stores it in the database with a 1-hour expiry. A reset link is emailed to you using Gmail via Nodemailer.
  • 3
    Click the link in the email. Enter your new password on reset-password.html.
  • 4
    The server validates the token (checks it exists and has not expired), hashes the new password, saves it, and clears the reset token. You can now log in with the new password.

4.3 Student Dashboard

Page: dashboard.html

When you log in, the dashboard instantly shows you a summary of your entire placement journey. All numbers are pulled live from the database every time you open the page.

📋 Total Applications

How many internships you have applied to so far.

⭐ Shortlisted

How many applications the admin has marked as "Shortlisted" for the next round.

🎉 Offered

How many times an admin has given you an official offer.

✅ Verified Skills

How many skills you have passed the AI quiz for and earned the "Verified" badge.

Profile Score (0–100): A single number that shows how complete your placement profile is.
Formula:
• +30 points if you have uploaded a resume
• +10 points per verified skill (up to 4 skills = maximum 40 points)
• +2 points per raw skill from resume (up to 10 skills = maximum 20 points)
The higher your score, the more attractive your profile is to admins.

4.4 Upload Resume (AI Parsing)

This is one of the most powerful features of the platform. Instead of manually adding skills, the system reads your resume and pulls skills out automatically.

  • 1
    Upload: On the dashboard, click "Upload Resume" and select your PDF resume file.
  • 2
    Text Extraction: The server uses pdf2json to read all the text inside your PDF — it scans every line of your resume.
  • 3
    Skill Matching: The extracted text is compared against a dictionary of 60+ tech skills, including:
    Python, Java, JavaScript, React, Node.js, MongoDB, AWS, Docker, Git, Machine Learning, Deep Learning, DevOps, Flutter, UI/UX, Figma, and many more.
  • 4
    Cloud Storage: Your PDF is uploaded to Supabase Storage with a unique filename (resume_[ID]_[timestamp].pdf). A permanent public URL is generated.
  • 5
    Database Update: Your profile is updated with the new skill list and resume URL. Previously verified skills that still appear in the new resume are kept; ones that do not appear are removed (to prevent fake skill carry-over from an old resume).
  • 6
    Instant Job Recommendations: The system immediately finds up to 5 internships that require the skills found in your resume and shows them to you as recommendations.
Result shown to you: A list of detected skills + top matching internships. Example: "Skills found: Python, React, Node.js. You match 3 open internships!"

4.5 Browse & Search Internships

The internship feed is not just a plain list — it is personalised to you based on your verified skills.

How Internships Are Shown

  • 1
    All active internships are fetched from the database, sorted by latest first.
  • 2
    For each internship, the system calculates a Match Score by comparing your verified skills against the required skills of that internship.
  • 3
    Internships are re-sorted by match percentage — the ones you are best suited for appear first.

Match Score Labels

Label Match Percentage What It Means
Perfect Match 100% You have every required skill — apply immediately.
Good Match 70% – 99% You have most skills. Strong application.
Partial Match 40% – 69% You have some skills. Consider learning the missing ones first.
Poor Match Below 40% You are missing most skills. Use the Skill Gap tool.

Search & Filter

You can also search internships by:

  • Keyword — company name, role title, or required skill
  • Mode — Remote, Hybrid, or On-site
  • Type — Internship or Job

4.9 AI Skill Verification (Quiz)

This is the feature that makes this platform unique. A skill is only considered truly yours after you pass a live AI-generated quiz on it.

Why is this important? Anyone can write "Python Expert" on a resume. But only someone who actually knows Python can pass a fresh, AI-generated quiz on it with no chance to look up the answers in advance.

How the Quiz Works — Step by Step

  • 1
    Trigger: On your dashboard, next to any skill extracted from your resume, click "Verify".
  • 2
    AI Generation: The server sends a request to Google Gemini AI (using the Gemini 2.5-flash model as primary, with fallback to 2.0-flash). The prompt says: "Act as a Technical Interviewer. Generate 5 MCQs for [skill name], progressively harder, in strict JSON format with correctIndex."
  • 3
    Server Splits the Data: The correct answers (correctIndex) are kept on the server in a session. Your browser only receives the questions and options — never the answers.
  • 4
    You Answer: The 5 questions appear in a timed popup. You select your answers and submit.
  • 5
    Grading: The server compares your answers to the stored correct answers. If you score 4 out of 5 (80%) or more, you pass.
  • 6
    On Pass: The skill is added to your verified_skills list in the database. It now shows a ✅ AI Verified badge. Your match scores with relevant internships are instantly recalculated and shown to you.
  • 7
    On Fail: The attempt is logged. You can try again but the system records all attempts — this prevents someone from spamming the quiz.
Emergency Backup Quiz: If the Gemini API is unavailable (e.g., no internet or API quota exceeded), the system automatically serves a built-in backup quiz so the feature never breaks.

After Passing — What You See

After passing a skill quiz, the system immediately tells you:

  • Your total number of verified skills
  • Top 5 internships you now match (sorted by match percentage)
  • For each internship: what skills you have vs. what you are still missing

4.10 AI Skill Gap Analysis & Learning Plan

Before applying to an internship, you can ask the AI: "What am I missing, and how do I learn it?"

  • 1
    Trigger: Click "Skill Gap" or "What am I missing?" on any internship card.
  • 2
    Diff Calculation: The system computes the difference between what the internship requires and what you have verified. Example: Required = {React, Node.js, MongoDB}. You have = {React, Node.js}. Missing = {MongoDB}.
  • 3
    If you are already fully qualified, it says: "You already have all the required skills!"
  • 4
    If you have missing skills, the AI generates a personalised 30-day learning plan in JSON format with:
    • A one-sentence overview of what needs to be done
    • 4 weekly goals, each focused on a specific skill
    • A free resource (YouTube channel, official docs, or website) for each week
    • A motivational tip to keep you going

4.11 View Quiz History

You can see a full log of every quiz you have ever taken. This shows the skill name, your score, whether you passed or failed, and the date. Up to 20 most recent attempts are shown. This lets you track your own learning progress over time.

AI Feedback on Quiz Results: After submitting a quiz, the AI also generates 3 sentences of personalised feedback — acknowledging your score, identifying the key concept to study, and recommending one free resource for improvement.

6. How the AI Features Work

Quiz Generation

The server connects to the Google Gemini API using a cascade of model fallbacks: Gemini 2.5-flash → 2.0-flash → gemini-flash-latest → gemini-pro-latest. If all models fail (e.g., API down), a built-in emergency quiz is served so the feature never breaks.

Anti-Cheat Design

Questions are generated fresh every single time. The correct answer index is:

  • Kept on the server — the browser never sees it
  • Never sent to the frontend until grading
  • Compared server-side when the student submits

This makes it impossible for a student to inspect the page source or network traffic to find the answers.

Skill Gap & Learning Plan (AI-Generated)

When you request a skill gap analysis, the AI creates a structured 4-week learning plan covering:

  • Which skill to focus on each week
  • What specific goal to achieve by end of that week
  • A free, named resource (YouTube channel, official docs, FreeCodeCamp, etc.)
  • A motivational tip

AI Feedback After Quiz

After you submit a quiz, the AI generates 3 sentences of personalised feedback: how you did, what concept to study next, and a specific free learning resource. This works even if you passed — it helps you go deeper.

7. Security & Data Protection

The platform implements industry-standard security measures. Here is what each one does in simple language:

🔐 Password Encryption (bcrypt)

Your password is passed through a one-way mathematical function with a random "salt" added. Even if the database is stolen, nobody can reverse-engineer your original password.

🎫 JWT Authentication

After login, you get a digital "pass" token. Every request you make carries this token. The server verifies it on every single protected action. Forged or expired tokens are immediately rejected.

🚦 Rate Limiting

A single IP address can make a maximum of 500 requests per 15 minutes. This stops bots from spamming the server or trying thousands of passwords in a brute-force attack.

🧹 Input Sanitisation

All inputs are validated using express-validator. Parameterised SQL queries prevent SQL Injection — nobody can enter code into a form field to attack the database.

🪖 Helmet.js Security Headers

Adds HTTP security headers to every response, protecting against XSS (cross-site scripting), clickjacking, and other common browser-based attacks.

🛑 Role-Based Access Control

Every admin-only action checks req.user.role === 'admin'. A student account can never access admin routes — the server returns 403 Forbidden instantly.

⏰ Password Reset Expiry

Reset tokens expire in exactly 1 hour. After that, the link becomes useless, even if someone intercepts the email.

💥 Crash Prevention

The server catches all uncaught exceptions and unhandled promise rejections. Instead of crashing, it logs the error and keeps running — ensuring 24/7 availability.
